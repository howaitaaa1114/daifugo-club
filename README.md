# 大富豪クラブ

AI3人と対戦するひとり用モードと、部屋コードまたは招待リンクで参加する2〜8人のオンライン対戦があります。

## 起動

Node.js 24 以上で、展開したフォルダーから `npm start` を実行し、
`http://localhost:3000` を開きます。依存パッケージのインストールは不要です。
同じネットワーク内の別端末から参加する場合は、起動したPCのLANアドレスを使います
（例 `http://192.168.1.10:3000`）。ホストもそのアドレスで開くと招待リンクを共有できます。
必要に応じて `PORT` と `HOST` で待受先を指定できます。

## 構成

| 階層 | 担当 |
| --- | --- |
| `game/` | カード、役、手番と順位の判定 |
| `server/` | 参加認証、対戦部屋API、対戦状態の保存、ローカルサーバー |
| `web/` | ロビー、対戦テーブル、設定と結果表示 |
| `worker/` | Sites用のサーバー入口 |
| `drizzle/` | 部屋テーブルのSQL |
| `scripts/` | Sites向けのビルド |

ローカルの部屋は `data/rooms.sqlite` に保存されます。最後に部屋の状態が変わってから
24時間で失効します。Sites向けのビルドは `npm run build` で作成します。
ホスティング環境では `DB` という名前のCloudflare D1バインディングを使用します。

## 実装した裁定

- ジョーカーはロビーで1枚か2枚を選べます。単体は最強で、組に含めた場合は同じ数字として役の枚数に含めます。
- パスは直前の出札に対してのみ有効です。誰かが新しく出札すると解除されます。
- 毎ラウンド席順をシャッフルし、♦3を持つ人から始めます。
- 9の効果は栗拾い、9リバース、効果なしから選べます。9リバースは出札ごとに手番の進む向きを反転し、場が流れたあとも続きます。
- 栗拾いは任意です。場から退いた札と10捨ての札が候補になり、ボンバーが手札から除外した札は候補に入りません。
- 12ボンバーはQの枚数分の異なる数字を指定し、使用者を含む全員の手札から対象を除外します。同時に手札がなくなった人は同順位です。
- 革命は同じ数字を4枚以上出すと発動します。革命中のイレブンバックは、場が流れるまで強さを通常順に戻します。
- ホストはロビーで役を個別に切り替えられます。初期設定は全項目オンです。
